# Product Design

## 제품 정의

유저가 가상의 캐릭터와 장기적으로 대화하면서, 캐릭터의 관계·감정·기억·세계 상태가 유저별로 변화하는 대화 서비스.

## 핵심 차별점

일반 챗봇:

```text
캐릭터 설정 + 대화 기록 → 응답
```

이 서비스:

```text
캐릭터 템플릿 + 유저별 캐릭터 인스턴스 + 관계 상태 + 기억 그래프 + 사건/시간 흐름 + 안전 경계 → 응답 + 상태 업데이트
```

## 핵심 사용자 경험

- 첫 대화에서는 모든 유저가 같은 캐릭터를 만난다.
- 시간이 지날수록 유저별 사건, 기억, 관계가 쌓인다.
- 같은 캐릭터라도 유저마다 다른 루트/세계선으로 진화한다.
- 대화는 단순 친밀도 상승이 아니라 캐릭터의 세계를 변화시킨다.

## MVP 범위

MVP에서 꼭 필요한 것:

1. 캐릭터 템플릿 관리
2. 유저별 캐릭터 인스턴스 생성
3. 관계 상태 수치 관리
4. 장기 기억 저장/검색
5. 이벤트 플래그와 route 상태
6. 프롬프트 조립기
7. 대화 후 상태 업데이트 엔진
8. 기본 안전 정책

MVP에서 미룰 수 있는 것:

- 복잡한 graph visualization
- 완전 자동 서사 생성 도구
- 다중 캐릭터 동시 관계망
- 실시간 음성/이미지 아바타
- 결제와 성장 이벤트 직접 연결

## 예시 서비스 루프

```text
사용자 메시지
→ 유저별 캐릭터 상태 로드
→ 시간 경과/기억 검색/이벤트 조건 확인
→ 캐릭터 내적 상태 산출
→ 응답 생성
→ 대화 후 상태 업데이트
→ memory/event/relationship 저장
```
